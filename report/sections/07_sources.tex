\section{Dataset and Code Provenance}
The input is \texttt{add.csv} from the Kaggle
\href{https://www.kaggle.com/datasets/uciml/internet-advertisements-data-set/data}{Internet Advertisements Data Set}.
The original UCI distribution supplies \texttt{ad.data},
\texttt{ad.names}, and \texttt{ad.DOCUMENTATION}
\citep{kushmerick1999}. The Kaggle CSV includes a header and exported
index. The term IDs follow the numeric headers, and their names were
verified against the original UCI column order.

The group's
\href{https://github.com/thuyhienle0904/internet-ads-btl}{GitHub repository}
requires access. The submission includes \texttt{analysis.R}, a single R
script with the original term-name mapping embedded, so the analysis can
be reproduced without repository access.

\section{Reproduction}
Place the unmodified \texttt{add.csv} in \path{data/raw/}. Run the
submitted \texttt{analysis.R} from that project root using base R.
The verification used R 4.6.2 on Windows with a UTF-8 locale.
\begin{lstlisting}[language={},caption={Command for reproducing the submitted analysis.}]
Rscript --encoding=UTF-8 analysis.R
\end{lstlisting}
The pipeline writes the cleaned dataset, column-name map, and audit
tables to \path{data/processed/}. EDA and inference outputs are written
to \path{output/eda-r/} and \path{output/inference/}. The split audit
records the input checksum and seed. The repository's equivalent
entry point is \path{scripts/run_all.R}, which reads
\path{data/reference/ad.names}.

For the one-file LaTeX submission, extract the supplied image archive
next to \path{report.tex} and compile with PDFLaTeX. In the repository,
\path{report/build.ps1} builds \path{report/thesis.tex} using MiKTeX and BibTeX.
