\section{Data and Reproduction}

The raw input is \texttt{add.csv} from the
\href{https://www.kaggle.com/datasets/uciml/internet-advertisements-data-set/data}{Internet Advertisements Data Set}.
The dataset creator is Nicholas Kushmerick; the original dataset is
identified by \href{https://doi.org/10.24432/C5V011}{DOI 10.24432/C5V011}.
The analysis source is maintained in the
\href{https://github.com/thuyhienle0904/internet-ads-btl}{group repository}.
The repository contains the preprocessing and descriptive-analysis scripts
and the figures embedded in this report.

The R preprocessing entry point is \texttt{scripts/01\_data\_setup.R},
which implements the procedure described in Chapter~3. It selects five
variables, applies mean imputation, recomputes aspect ratios, excludes
missing Local values, and removes repeated combinations on the selected
variables. The R EDA entry point is
\texttt{scripts/02\_eda\_descriptive.R}; its outputs are written to
\texttt{output/eda-r/}, and its eight figures are copied to
\texttt{report/figures/eda/} for LaTeX compilation.

An independent Python workflow,
\texttt{scripts/eda\_kaggle\_snapshot.py}, reproduces the preprocessing
from \texttt{data/raw/add.csv}, exports the five-variable processed CSV,
and generates the tables and figures in \texttt{output/eda/}.
The source SHA-256 checksum and preprocessing counts are recorded with
the outputs. Python figures provide an independent comparison; the report embeds
the figures generated by the R EDA entry point.
The integrated R preprocessing and EDA scripts were validated with
R 4.6.2 in an isolated copy of the project. The synthetic EDA checks
passed, all eight PNG figures were generated, and the processed records
and numerical tables agreed with the Python results within floating-point
tolerance. Execution logs and comparison results are retained under
\texttt{output/validation-r/}.
