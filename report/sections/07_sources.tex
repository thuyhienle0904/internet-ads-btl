\section{Data and Reproduction}

The raw input is \texttt{add.csv} from the
\href{https://www.kaggle.com/datasets/uciml/internet-advertisements-data-set/data}{Internet Advertisements Data Set}.
The dataset creator is Nicholas Kushmerick; the original dataset is
identified by \href{https://doi.org/10.24432/C5V011}{DOI 10.24432/C5V011}.
The analysis source is maintained in the
\href{https://github.com/thuyhienle0904/internet-ads-btl}{group repository}.
The updated scripts are also included in the local handoff package.

The verified workflow runs \texttt{scripts/eda\_kaggle\_snapshot.py}
on \texttt{data/raw/add.csv} with Python and Matplotlib. It first writes
the processed CSV and dictionary, then reads that CSV to generate the
tables and figures in \texttt{output/eda/}. The audit records the
SHA-256 checksum of the raw input. The corresponding R entry points
are \texttt{scripts/01\_data\_setup.R} and
\texttt{scripts/02\_eda\_descriptive.R}; they have not yet been run in
the current environment.
