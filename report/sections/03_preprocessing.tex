\section{Input Validation and Deduplication}

The input contains 3,279 records and 1,560 columns, including the
exported index. The preprocessing script validates the header, index,
and class labels. It retains all 1,558 original features.

Exact duplicates are identified across the original features and
\texttt{IsAds} after trimming whitespace. The index is excluded from
this comparison and retained as \texttt{row\_id} for traceability.
The first occurrence is retained, removing 856 redundant rows.
Three original feature vectors occur with both class labels and are
retained because the label forms part of the duplicate key.

\begin{lstlisting}[style=edaR,aboveskip=4pt,belowskip=4pt]
# original contains the feature and label columns, excluding row_id.
duplicate <- duplicated(original)
keep <- !duplicate
retained <- original[keep, , drop = FALSE]
\end{lstlisting}

\section{Missing Values}

The script converts missing-value markers to \texttt{NA} and preserves
observed dimensions and aspect ratios. Rows with missing Local values
are retained. The number of missing cells falls from 2,729 to 1,473
as a result of removing duplicate rows.

The \texttt{missing\_size} flag marks any original feature missing.
It flags 499 retained records, including 492 missing a geometric value
and seven missing only Local. The script exports 2,423 rows and 1,561
columns, a data dictionary and audit tables for Chapter~4.
