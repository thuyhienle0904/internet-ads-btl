\section{Input Validation and Deduplication}

The input contains 3,279 records and 1,560 columns, including the
exported index. The preprocessing script validates the header, index,
and class labels. It retains all 1,558 original features.

Exact duplicates are identified across the original features and
\texttt{IsAds} after trimming whitespace. The index is excluded from
this comparison and retained as \texttt{row\_id} for traceability.
The first occurrence is retained, removing 856 redundant rows.
Three original feature vectors occur with both class labels and are
retained because the label forms part of the duplicate key.

\begin{lstlisting}[style=edaR]
# original contains the feature and label columns, excluding row_id.
duplicate <- duplicated(original)
keep <- !duplicate
retained <- original[keep, , drop = FALSE]
\end{lstlisting}

\section{Missing Values}

The script converts missing-value markers to \texttt{NA} and preserves
observed dimensions and aspect ratios. Rows with missing Local values
are retained. The number of missing cells falls from 2,729 to 1,473
as a result of removing duplicate rows.

\begin{table}[htbp]
\centering
\caption{Missing values before and after deduplication.}
\begin{tabular}{lrr}
\toprule
Feature & Raw & Processed\\
\midrule
Height & 903 & 487\\
Width & 901 & 483\\
Aspect ratio & 910 & 492\\
Local & 15 & 11\\
\bottomrule
\end{tabular}
\end{table}

The derived variable \texttt{missing\_size} equals 1 when any original
feature is missing and 0 otherwise. It flags 499 retained records.
Of these, 492 lack at least one of the three geometric variables and
seven lack only Local. The field name is retained from the preprocessing
schema.

\begin{lstlisting}[style=edaR]
# parsed contains only the 1,558 original features.
processed$missing_size <- as.integer(rowSums(is.na(parsed)) > 0)
\end{lstlisting}

\section{Output and Validation}

The processed dataset contains 2,423 rows and 1,561 columns, with
386 advertisements and 2,037 non-advertisements. The R script exports
the processed CSV, data dictionary, class counts, missingness summaries,
and a row-level audit of the original indices and retention decisions.
This dataset is the input to Chapter~4.
