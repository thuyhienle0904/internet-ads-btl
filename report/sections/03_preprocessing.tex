\section{Processing Workflow}

The preprocessing procedure follows the five-variable branch of the
reference report. The source CSV contains 3,279 observations and 1,560
columns, including an exported index. The header was interpreted as
column metadata, and the index sequence from 0 to 3,278 was validated.
The selected source columns were 0, 1, 2, 3, and 1558, renamed
\texttt{Height}, \texttt{Width}, \texttt{Aspect\_Ratio}, \texttt{Local},
and \texttt{IsAds}. Whitespace was trimmed before missing-value markers
were converted to \texttt{NA}. The labels \texttt{ad.} and
\texttt{nonad.} were retained.

The observed means were calculated before row removal:
\[
 \bar H_{\mathrm{obs}}=64.02188552188552,\qquad
 \bar W_{\mathrm{obs}}=155.3448275862069.
\]
Missing height and width values were replaced by these respective means.
All aspect ratios, including previously observed ratios, were recomputed
as Width/Height. The 15 observations missing Local were then excluded.
Exact duplicates on the five selected variables, including the label,
were removed by retaining the first occurrence.

\subsection{Input Validation and Type Conversion}

The CSV is read as character data to preserve missing-value markers
until explicit normalization. Header and index checks establish that
subsequent selection refers to the intended source columns.

\begin{lstlisting}[style=edaR]
raw <- read.csv(
  "data/raw/add.csv", header = TRUE,
  check.names = FALSE, colClasses = "character",
  stringsAsFactors = FALSE, na.strings = NULL
)
stopifnot(nrow(raw) == 3279L, ncol(raw) == 1560L)
stopifnot(identical(names(raw),
                    c("", as.character(0:1558))))
stopifnot(identical(raw[[1]], as.character(0:3278)))
full <- as.data.frame(lapply(raw[-1], trimws),
                      stringsAsFactors = FALSE)
names(full) <- as.character(0:1558)
selected <- full[c("0", "1", "2", "3", "1558")]
names(selected) <- c("Height", "Width", "Aspect_Ratio",
                     "Local", "IsAds")
for (v in names(selected)[1:4]) {
  text <- selected[[v]]
  text[text %in% c("?", "")] <- NA_character_
  number <- suppressWarnings(as.numeric(text))
  stopifnot(!any(!is.na(text) & is.na(number)))
  stopifnot(all(is.finite(number[!is.na(number)])))
  selected[[v]] <- number
}
stopifnot(all(selected$IsAds %in% c("ad.", "nonad.")))
selected$IsAds <- factor(selected$IsAds,
                         levels = c("ad.", "nonad."))
\end{lstlisting}

\texttt{trimws} removes surrounding whitespace before marker recognition.
The conversion checks detect unexpected text and non-finite measurements.
The full script additionally checks positive observed heights and widths,
binary Local values, and the expected missing-value counts.

\subsection{Imputation, Ratio Recalculation, and Deduplication}

\begin{lstlisting}[style=edaR]
mean_height <- mean(selected$Height, na.rm = TRUE)
mean_width <- mean(selected$Width, na.rm = TRUE)
data_mean <- selected
data_mean$Height[is.na(data_mean$Height)] <- mean_height
data_mean$Width[is.na(data_mean$Width)] <- mean_width
data_mean$Aspect_Ratio <- data_mean$Width / data_mean$Height
after_local <- data_mean[!is.na(data_mean$Local), ,
                          drop = FALSE]
dup_five <- duplicated(after_local)
processed <- after_local[!dup_five, , drop = FALSE]
rownames(processed) <- NULL
\end{lstlisting}

The means use the original observed values before any rows are removed.
For comparison, the original medians are 51 px for height and 110 px for
width. The implemented branch uses the means to reproduce the reference
preprocessing. Aspect ratio is recalculated for every row after imputation,
and computations retain full precision before duplicate detection.
\texttt{duplicated} compares all five columns, including the label,
and identifies occurrences beyond the first. The Local filter precedes
this step, leaving 3,264 rows for duplicate detection.

The data dictionary records source columns, types, units, and processing

\section{Methodological Scope}

The 2,214 excluded rows represent repeated combinations of five processed
variables. A full-record audit of the original features and labels,
excluding the index, identifies 856 repeated rows beyond first occurrences.
These two counts use different definitions. Distinct images can have
identical values on the selected variables, and mean imputation can
create additional repeated combinations. The reduction also changes the
advertisement share from 14.00\% to 8.86\%.

This procedure reproduces the reference report's mean-imputed branch.
It provides the common input for Chapter~4. The reference report's later
median-imputed modeling branch is separate. Mean imputation from the full
sample serves the present descriptive replication; predictive evaluation
requires a training/test design with imputation parameters estimated
within the training partition.
