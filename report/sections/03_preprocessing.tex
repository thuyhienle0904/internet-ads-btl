\section{Input Validation and Deduplication}

The input contains 3,279 records and 1,560 columns, including the
exported index. The preprocessing script validates the header, index,
and class labels. It retains all 1,558 original features.

Exact duplicates are identified across the original features and
\texttt{IsAds} after trimming whitespace. The index is excluded from
this comparison and retained as \texttt{row\_id} for traceability.
The first occurrence is retained, removing 856 redundant rows.
Three original feature vectors occur with both class labels and are
retained because the label forms part of the duplicate key.

\begin{lstlisting}[style=edaR,aboveskip=4pt,belowskip=4pt]
# original contains the feature and label columns, excluding row_id.
duplicate <- duplicated(original)
keep <- !duplicate
retained <- original[keep, , drop = FALSE]
\end{lstlisting}

\section{Missing Values}

The script converts missing-value markers to \texttt{NA} and preserves
observed dimensions and aspect ratios. Rows with missing Local values
are retained. The number of missing cells falls from 2,729 to 1,473
as a result of removing duplicate rows.

\begin{table}[htbp]
\centering
\caption{Missing values before and after deduplication.}
\label{tab:preprocessing-missing}
\begin{tabular}{lrr}
\toprule
Feature & Raw & Processed\\
\midrule
Height & 903 & 487\\
Width & 901 & 483\\
Aspect ratio & 910 & 492\\
Local & 15 & 11\\
\bottomrule
\end{tabular}
\end{table}

The \texttt{missing\_size} flag marks any original feature missing.
It flags 499 retained records, including 492 missing a geometric value
and seven missing only Local. The script exports 2,423 rows and 1,561
columns, a data dictionary and audit tables for Chapter~4.

\section{Data Formatting and Variable Handling}

This section records how the data were formatted, which variables were
added or removed, and how variables were transformed.
Table~\ref{tab:preprocessing-variables} summarizes these operations.

\begin{table}[htbp]
\centering
\caption{Formatting, variable and transformation steps in preprocessing.}
\label{tab:preprocessing-variables}
\small
\begin{tabular}{@{}p{2.9cm}p{11.2cm}@{}}
\toprule
Step & Treatment\\
\midrule
Formatting & Whitespace is trimmed, the markers \texttt{?} and empty
strings become \texttt{NA}, and all feature columns are parsed as numbers.
The script stops if a non-numeric value remains.\\
Validation & Height, Width and Aspect\_Ratio must be positive. Local and
the 1,554 term indicators must be 0, 1 or \texttt{NA}.\\
Variables added & \texttt{missing\_size}, equal to 1 if any original
feature is missing. The export index is kept as \texttt{row\_id}.\\
Variables removed & None. All 1,558 original features are kept; only
the 856 redundant rows are removed.\\
Transformations & The numeric headers are renamed to Height, Width,
Aspect\_Ratio, Local and \texttt{term\_0004} to \texttt{term\_1557}. The
label becomes the factor \texttt{IsAds} (levels \texttt{ad.},
\texttt{nonad.}).\\
\bottomrule
\end{tabular}
\end{table}

No value is scaled, imputed or recalculated at this stage. In particular,
the original Aspect\_Ratio is retained rather than recomputed from Width and
Height. The processed file therefore differs from the raw file only by the
removed duplicate rows, the new column names and the added
\texttt{missing\_size} column. Missing values stay as \texttt{NA}, so any
imputation required by a model can be fitted on training data only in the
modelling chapter.
