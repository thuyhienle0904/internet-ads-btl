\section{Processing Workflow}

Data preprocessing comprised input validation, column identification,
missing-value standardization, label normalization, and an audit of
repeated observations. The first row of the Kaggle CSV was interpreted
as column metadata. The exported index was checked against the sequence
from 0 to 3,278 and excluded from the analytical variables. Descriptive
names were assigned to the geometric measurements and the
\texttt{local} indicator. A data dictionary documented the correspondence
between processed variables and their original column headers.
Table~\ref{tab:preprocessing-decisions} summarizes the processing steps
and their methodological rationale.

\section{Output and Validation}

The processed dataset contains 3,279 observations and 1,559 columns,
comprising 1,558 features and one target label. All observations were
retained. The audit identified 856 exact repeated feature-and-label rows
beyond their first occurrences and 2,729 missing cells. The numbers of
missing values in height, width, aspect ratio, and \texttt{local} are
903, 901, 910, and 15, respectively. These counts refer to individual
cells; observations with multiple missing attributes contribute to
more than one feature count.

The processed dataset was exported as
\texttt{internet\_ads\_processed.csv} for the descriptive analysis.
The companion \texttt{data\_dictionary.csv} records each variable's
source header, data type, measurement unit, and missing-value count.
Missing measurements were preserved as \texttt{NA}, and numerical
features retained their original scales. Descriptive summaries therefore
use the available observations for each variable and report their
respective sample sizes.

The retained missing values and repeated records are relevant to
subsequent modeling. Data-dependent transformations require estimation
within the training partition to prevent information leakage.
Repeated records also warrant assessment during partition design,
since related observations appearing in both training and test sets
can lead to optimistic estimates of predictive performance.
